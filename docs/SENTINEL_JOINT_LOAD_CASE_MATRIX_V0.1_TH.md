# ตารางกรณีรับแรงของข้อต่อ Sentinel v0.1
**สถานะ:** กรอบงานวิศวกรรม ยังไม่ได้คำนวณแรงสำหรับฮาร์ดแวร์ขั้นสุดท้าย

## 1. วัตถุประสงค์และสมมติฐาน
ตารางนี้แปลงภารกิจตัวแทนที่กำหนดไว้เป็นกรณีรับแรงทางกลที่ทำซ้ำได้สำหรับหุ่นยนต์สี่ขา โดยยังไม่สมมติจำนวนแกนข้อต่อขั้นสุดท้าย รูปแบบข้อต่อ gait ความยาวขา หรือชนิด actuator

เป้าหมายน้ำหนักหุ่นยนต์ทั้งระบบเบื้องต้นคือ 18–22 kg เพื่อให้เห็นภาพเท่านั้น หากยืนสมมาตรและแบ่งแรงเท่ากันทั้งสี่เท้า:
\[
F_{foot,static}=\frac{mg}{4}=44.1\text{–}53.9\;N
\]
โดยใช้ความเร่งโน้มถ่วงมาตรฐาน 9.81 m/s² ค่านี้เป็นเพียงค่าประมาณอ้างอิงขณะยืนนิ่งอย่างสมมาตร ไม่ใช่แรงสูงสุดขณะเคลื่อนที่ พิกัด actuator แรงกระแทก safety factor หรือหลักฐานว่าโครงสร้างแข็งแรงเพียงพอ แรงจริงขึ้นกับจุดศูนย์ถ่วง การสัมผัสพื้น ท่าทาง ความเร่ง และ gait

## 2. ตารางกรณีรับแรง
| ID | สถานการณ์ | ข้อมูลนำเข้าที่ต้องมี | ผลลัพธ์ / การตรวจสอบ |
|---|---|---|---|
| JL-01 | ยืนนิ่งโดยใช้เท้าทั้งสี่ | น้ำหนักรวม payload จุดศูนย์ถ่วง พิกัดเท้า ท่าทาง | แรงปฏิกิริยาที่เท้า แรงบิดจากแรงโน้มถ่วง และเสถียรภาพสถิต |
| JL-02 | รองรับด้วยสามเท้าหรือมีการถ่ายน้ำหนักชั่วคราว | ชุดเท้าที่สัมผัสพื้น จุดศูนย์ถ่วง ท่าทาง ความเร่ง | แรงไม่เท่ากันในแต่ละเท้า ขาที่รับแรงสูงสุด และระยะเผื่อการพลิกคว่ำ |
| JL-03 | รองรับด้วยเท้าทแยงสองข้างระหว่าง gait หากเลือกใช้ | ลำดับ gait duty factor เฟส และการเคลื่อนที่ลำตัว | แรงรองรับสูงสุดและแรงบิดข้อต่อ |
| JL-04 | ยกและวางขาที่ไม่รองรับน้ำหนัก | มวลขา จุดศูนย์กลางมวลแต่ละท่อน ความเร่งเชิงมุม วิถีเท้า | แรงบิด ความเร็ว และกำลังของข้อต่อขณะเหวี่ยงขา |
| JL-05 | เริ่มเดิน / หยุด / เร่งตามแนวทางเดิน | ความเร่งเป้าหมาย แรงยึดเกาะ มวลตัวและ payload | แรงเฉื่อย แรงบิดข้อต่อ และความเสี่ยงลื่น |
| JL-06 | เลี้ยว / ความเร่งด้านข้าง | รัศมีเลี้ยวหรือ yaw rate ความเร็ว ความสูงจุดศูนย์ถ่วง | การถ่ายน้ำหนักด้านข้าง แรงบิด และเสถียรภาพ |
| JL-07 | เดินขึ้น/ลงทางลาดตามขอบเขตชั่วคราว 5° | ความลาดชัน แรงเสียดทาน ท่าทาง ความเร็ว วิธีเบรก | องค์ประกอบแรงโน้มถ่วง ระยะเผื่อแรงยึดเกาะ แรงที่ข้อต่อและเท้า |
| JL-08 | เดินผ่านรอยต่อพื้น / ธรณี | ความสูงที่วัดจริง รัศมีขอบ มุมเข้าหา ขนาดเท้า ความเร็ว | ประมาณแรงกระแทก แรงสูงสุดที่ข้อต่อ และระยะยกเท้า |
| JL-09 | เท้าลื่นโดยไม่คาดคิด | ค่าประมาณแรงเสียดทาน ความเร็วลื่น เวลาตรวจจับ วิธีฟื้นตัว | แรงบิด/ความเร็วเพื่อฟื้นตัว เสถียรภาพ และการหยุดอย่างปลอดภัย |
| JL-10 | หยุดแบบควบคุม / คงท่าเมื่อเกิดข้อขัดข้อง | ประเภท fault ความเร็วลำตัว สถานะเท้ารองรับ เวลาหยุด | แรงบิดเบรก/คงท่า ท่าปลอดภัย และขีดจำกัดความร้อน/ไฟฟ้า |
| JL-11 | payload และจุดศูนย์ถ่วงกรณีสุดขอบ | มวล payload ตำแหน่งติดตั้ง ค่าคลาดเคลื่อน | แรงบิดสูงสุด แรงรองรับ และเสถียรภาพ |
| JL-12 | แรงกระแทก / สะดุด / การรับแรงจากการล้ม | เหตุการณ์ที่กำหนด ความเร็วก่อนกระแทก compliance ความหน่วงที่ยอมรับ | แรงชั่วขณะ ความเค้นโครงสร้าง และการตอบสนอง actuator |
| JL-13 | duty cycle ภารกิจซ้ำ | ประวัติแรงบิดและความเร็วของแต่ละข้อต่อตามเวลา | แรงบิด RMS ความร้อนสะสม และภาระความล้า |
| JL-14 | กลับหรือหยุดเมื่อพลังงานต่ำ | พลังงานใช้ได้ที่เหลือ สถานะเส้นทาง พื้นที่ และ fault | ความเป็นไปได้ในการหยุด/กลับอย่างปลอดภัยและพลังงานสำรอง |

ไม่ใช่ทุกกรณีเป็นสภาวะที่อนุญาตให้ใช้งาน JL-08 ถึง JL-12 เป็นกรณีอันตรายหรือกรณีตรวจสอบความทนทาน ต้องวางแผนจำลองหรือทดสอบแบบควบคุมอย่างรอบคอบก่อนสัมผัสจริง

## 3. วิธีคำนวณ
กำหนดมวล จุดศูนย์กลางมวล กรอบพิกัด และ tensor ความเฉื่อยของลำตัวและแต่ละท่อนขา สร้าง support polygon และสถานะการสัมผัสพื้นในแต่ละช่วงเวลา จากนั้นแก้สมดุลแรงและโมเมนต์ทั้งระบบ แล้วใช้ inverse kinematics/dynamics เพื่อกระจายภาระไปยังข้อต่อ

สำหรับท่าทางกึ่งสถิต:
\[
\sum_i \mathbf{F}_i + m\mathbf{g}=0,\qquad
\sum_i (\mathbf{r}_i\times\mathbf{F}_i)+\mathbf{M}_{ext}=0
\]

สำหรับพลวัตของกลไกหลายข้อต่อ ให้ใช้ rigid-body model ที่ผ่านการตรวจสอบหรือวิธีเทียบเท่า:
\[
\boldsymbol{\tau}=\mathbf{M}(q)\ddot q+\mathbf{C}(q,\dot q)\dot q+\mathbf{g}(q)+\boldsymbol{\tau}_{friction}-\mathbf{J}(q)^T\mathbf{F}_{contact}
\]
ต้องกำหนดเครื่องหมายให้สอดคล้องกันทั้งแบบจำลอง สมการนี้เป็นกรอบการสร้างแบบจำลอง ไม่สามารถให้ค่าแรงบิดเชิงตัวเลขได้หากไม่มีรูปทรง มวลเฉื่อย การเคลื่อนที่ และข้อมูลการสัมผัสพื้น

## 4. ข้อมูลที่ต้องบันทึกในแต่ละกรณี
รหัสกรณี ช่วงภารกิจ รูปแบบหุ่นยนต์ มวลรวมและมวลแต่ละส่วน payload จุดศูนย์ถ่วง รูปทรง พิกัดข้อต่อ ชุดเท้าที่สัมผัสพื้น สมมติฐาน/หลักฐานแรงเสียดทาน ความเร็วและความเร่ง แรงรบกวนภายนอก เวอร์ชันแบบจำลอง ค่าตั้ง solver ผลลัพธ์ ความไม่แน่นอน เหตุผลของ safety factor ผู้ทบทวน และเกณฑ์ผ่าน/ไม่ผ่าน

## 5. จากแรงข้อต่อสู่ข้อกำหนด actuator
คำนวณแยกตามข้อต่อ:
- แรงบิดบวก/ลบสูงสุด พร้อมระยะเวลาและความถี่การเกิด
- แรงบิดต่อเนื่องและ RMS ตลอดภารกิจตัวแทน
- ความเร็ว ความเร่ง และจุดทำงาน torque-speed ที่เกิดพร้อมกัน
- กำลังกล \(P=\tau\omega\) รวมพฤติกรรมการคืนพลังงานหรือการระบายพลังงานหากเกี่ยวข้อง
- ประสิทธิภาพชุดส่งกำลัง backlash ความยืดหยุ่น ความต้านทานความร้อน และอุณหภูมิที่ยอมรับได้
- แรงบิดคงท่า พฤติกรรมเมื่อไม่มีไฟ ความจำเป็นของเบรก/กลไกรองรับ และการตอบสนองเมื่อ fault

ห้ามเลือก actuator จากแรงบิดสถิตเพียงค่าเดียว และห้ามเทียบแรงบิดมอเตอร์กับแรงบิดขาออกที่ข้อต่อโดยไม่คำนึงถึงอัตราทด ประสิทธิภาพ ขีดจำกัดความร้อน และ duty cycle

## 6. ลำดับงานวิศวกรรม
1. สร้าง geometry และ mass-property model แบบมีเวอร์ชันสำหรับคำนวณ (ยังไม่ใช่การตรึงแบบผลิตภัณฑ์ขั้นสุดท้าย)
2. กำหนด gait และช่วงการรองรับแต่ละแบบ โดยแยกทางเลือกให้ชัดเจน
3. สร้าง motion profile ของภารกิจตามเวลา
4. ตรวจสอบกึ่งสถิต แล้วจึงคำนวณ dynamic inverse dynamics
5. วิเคราะห์ช่วง payload จุดศูนย์ถ่วง แรงเสียดทาน ความลาดชัน และความไม่แน่นอน
6. ระบุขอบเขต actuator ทั้งค่าสูงสุดและ RMS
7. ส่งประวัติแรงบิด/ความเร็ว/กระแสเข้าสู่แบบจำลองแบตเตอรี่และความร้อน
8. ปรับปรุง mass budget และคำนวณวนซ้ำจนแบบจำลองลู่เข้าตามค่าคลาดเคลื่อนที่กำหนด

## 7. ข้อมูลที่ยังขาด
จำนวนและแกนข้อต่อ ความยาวท่อนขา รูปทรงเท้า มวลและ inertia ของแต่ละส่วน gait แรงเสียดทานขณะสัมผัสพื้น payload จุดศูนย์ถ่วง โปรไฟล์ความเร็ว/ความเร่ง รูปทรงธรณี สมมติฐานแรงกระแทก และสถาปัตยกรรม actuator ยัง TBD ต้องใช้ข้อมูลวัดจริงหรือแหล่งข้อมูลตรวจสอบย้อนกลับได้ ห้ามแต่งตัวเลขเพื่อเติมช่องว่าง

## 8. ขอบเขตความปลอดภัยและหลักฐาน
ตารางนี้เป็นแผนคำนวณ ไม่ใช่หลักฐานว่าหุ่นยนต์เดิน ทรงตัว ต้านการล้ม ข้ามสิ่งกีดขวาง หรือมีสมรรถนะ actuator ที่ผ่านการยืนยันแล้ว เอกสารนี้ไม่อนุมัติการจัดซื้อ ผลิต หรือใช้งานภาคสนาม ต้องคงการตรวจสอบแหล่งกำเนิดชิ้นส่วนและผู้ผลิตตามนโยบาย PUI89 ที่ไม่พึ่งพาสิ่งที่มีต้นกำเนิดจากจีนหรืออยู่ภายใต้การควบคุมจากจีน
