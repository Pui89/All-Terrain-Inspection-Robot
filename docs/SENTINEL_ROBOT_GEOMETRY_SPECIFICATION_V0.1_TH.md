# ข้อกำหนดรูปทรงเรขาคณิตหุ่นยนต์ Sentinel v0.1
**สถานะ:** ข้อกำหนดตัวแปรสำหรับสร้างแบบจำลองทางวิศวกรรม ยังไม่มีการตรึงมิติใด ๆ

## 1. วัตถุประสงค์
กำหนดข้อมูลรูปทรงและคุณสมบัติมวลที่จำเป็น ก่อนจะคำนวณจลนศาสตร์ เสถียรภาพ inverse dynamics ขนาด actuator และการจัดวางอุปกรณ์ได้อย่างน่าเชื่อถือ เอกสารนี้กำหนดตัวแปรและวิธีวัด โดยไม่แต่งค่ามิติขึ้นเอง

## 2. กรอบพิกัด
กำหนดระบบพิกัดแบบ right-handed ที่สอดคล้องกันและบันทึกไว้:
- **World frame W:** กรอบอ้างอิงคงที่ของพื้นที่ตรวจสอบที่สำรวจแล้ว
- **Body frame B:** จุดกำเนิดอยู่ที่จุดอ้างอิงบนลำตัวที่ประกาศชัด แกนสอดคล้องกับ chassis
- **Hip/joint frames H_i / J_i:** กำหนดหนึ่งกรอบต่อขาและข้อต่อ พร้อมทิศแกนและมุมศูนย์
- **Foot frame F_i:** จุดกำเนิดที่ตำแหน่งอ้างอิงการสัมผัสพื้นของเท้า
- **Sensor frames S_i:** transform ที่สอบเทียบจากเซนเซอร์แต่ละตัวไปยัง B

บันทึกวิธีแปลงพิกัด หน่วย ผู้รับผิดชอบกรอบพิกัด วิธีสอบเทียบ และเวอร์ชัน ใช้ชื่อกรอบและเครื่องหมายแกนให้ตรงกันใน CAD, simulation, firmware และบันทึกการทดสอบ

## 4. คุณสมบัติมวล
สำหรับทุกชิ้นส่วนและชุดประกอบ ให้บันทึก:
- รหัสชิ้นส่วน/ชุดประกอบและ revision
- วัสดุ กระบวนการผลิต และแหล่งกำเนิดที่ตรวจสอบได้
- มวลจาก CAD และจุดศูนย์กลางมวลที่คำนวณ
- inertia tensor และกรอบพิกัดอ้างอิง
- รายการ fastener สายไฟ connector ฝาครอบ และอุปกรณ์ซ่อมที่รวมหรือไม่รวม
- แหล่งข้อมูลความหนาแน่น/วัสดุและค่าความไม่แน่นอน
- มวลที่ชั่งจริงและผลการวัดสมดุล/จุดศูนย์ถ่วงเมื่อมีชิ้นงานจริง

แยกน้ำหนักพื้นฐานของหุ่นยนต์ทั้งระบบออกจาก payload ภารกิจ เป้าหมายเบื้องต้น 18–22 kg ครอบคลุมหุ่นยนต์ทั้งระบบตามนิยามในเอกสาร mass budget ห้ามละเลยขา เท้า actuator แบตเตอรี่/BMS compute เซนเซอร์พื้นฐาน สายไฟ หรือฝาครอบโดยไม่ระบุ

## 5. ข้อมูลจลนศาสตร์และเสถียรภาพ
ก่อนคำนวณ workspace หรือเสถียรภาพ ต้องกำหนด:
- แกนข้อต่อ ช่วงการหมุน ขีดจำกัดความเร็วและความเร่ง
- ความยาว link และขอบเขตการชนกัน
- รูปทรงจุดสัมผัสเท้าและมุมสัมผัสที่ยอมรับได้
- ความกว้าง/ยาว stance และความสูงลำตัวปกติ
- จุดศูนย์ถ่วงในรูปแบบไม่มี payload, baseline และ payload
- support polygon และวิธีคำนวณ stability margin
- หลักฐานแรงเสียดทานระหว่างเท้ากับพื้นและค่าความไม่แน่นอน
- การบดบังของเซนเซอร์และ payload ตลอด workspace ของขาและลำตัว

การตรวจ support polygon แบบสถิตไม่สามารถใช้แทนการวิเคราะห์ dynamic stability ได้ การทรงตัวแบบพลวัต การตรวจจับการล้ม และการกู้คืนต้องใช้แบบจำลองตามเวลาและเงื่อนไขทดสอบปลอดภัยที่กำหนดแยกต่างหาก

## 6. ข้อกำหนดคุณภาพ CAD และแบบจำลอง
- ใช้ assembly tree ที่ควบคุมเวอร์ชัน พร้อม part number และ revision
- กำหนดวัสดุจริงและเผื่อน้ำหนัก fastener/สายไฟอย่างสมเหตุสมผล
- หลีกเลี่ยง geometry ซ้ำหรือซ่อนที่ทำให้ mass properties ผิดเพี้ยน
- กำหนด joint mates/constraints และตรวจสอบ degrees of freedom
- ส่งออก geometry format กลางที่มีเวอร์ชันสำหรับ simulation เมื่อทำได้
- ตรวจสอบน้ำหนักจาก CAD เทียบกับ spreadsheet หรือ script อิสระ
- บันทึก simplification ของแบบจำลอง ชิ้นส่วนที่ละไว้ และความไม่แน่นอน
- ทำให้ source CAD และผลวิเคราะห์ที่สร้างขึ้นตรวจสอบย้อนกลับได้

## 7. ผลงานที่ต้องมี ก่อนเลือก actuator
1. แบบ chassis และ layout ขาทั้งสี่ที่มีมิติ
2. ตารางแกนและช่วงการหมุนข้อต่อ
3. รูปทรง link/เท้าและขอบเขตการชน
4. ทะเบียนมวล จุดศูนย์ถ่วง และ inertia รายชิ้นส่วน
5. ขอบเขตติดตั้ง payload และเซนเซอร์
6. รูปแบบจุดศูนย์ถ่วงปกติและกรณีสุดขอบ
7. ผลตรวจ kinematic reachability และ self-collision
8. ผลตรวจ static support และ dynamic stability เบื้องต้น
9. mass budget ที่ปรับปรุงพร้อมค่าความไม่แน่นอน
10. บันทึกการทบทวนและอนุมัติแบบจำลอง

## 8. ประเด็นที่ยังไม่ตัดสินใจ
มิติทั้งหมด วัสดุ จำนวน/ชนิดข้อต่อ topology ของระบบขับเคลื่อน การออกแบบเท้า payload ตำแหน่งเซนเซอร์ ตำแหน่งแบตเตอรี่ ฝาครอบ ทางระบายความร้อน การเดินสาย และกระบวนการผลิตยังเปิดอยู่ ยังไม่มีการเลือกผู้ผลิต มอเตอร์ เกียร์ หรือแบตเตอรี่

## 9. ขอบเขตหลักฐาน
เอกสารนี้เป็นทะเบียนตัวแปรและข้อกำหนดการสร้างแบบจำลอง ไม่ใช่แบบ CAD แบบผลิต บันทึกต้นแบบ หรือหลักฐานว่าหุ่นยนต์เคลื่อนที่ได้จริง ห้ามใช้ geometry สมมติเป็นข้อกำหนดผลิตภัณฑ์ที่ผ่านการยืนยัน เอกสารนี้ไม่อนุมัติการจัดซื้อ ผลิต ประกอบ หรือใช้งานภาคสนาม ต้องปฏิบัติตามข้อกำหนดแหล่งกำเนิด ความสามารถซ่อมแซม การออกแบบโมดูลาร์ และนโยบาย PUI89 ที่ไม่พึ่งพาสิ่งที่มีต้นกำเนิดจากจีนหรืออยู่ภายใต้การควบคุมจากจีน
